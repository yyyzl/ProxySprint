打开方式
双击 index.html 查看 12 个界面的目录，或直接打开任意编号 HTML。
所有样式、脚本和 Alpine.js 均随目录提供，不需要外网或开发环境。
请保留整个目录结构。app.html 支持 ?state=done 等状态参数。

本次设计范围
沿用已确认的 Windows 设计稿：奶油暖底、深墨文字、蓝色主操作、浅黄地区选择。
保留左侧配置、右侧结果、标准 Windows 标题栏的布局。
名称包含 / 排除放在高级筛选里，默认留空，不限制节点。
主视口 1280 × 860；检查较窄的桌面窗口及移动宽度，作为重排验证。
初始选择 ChatGPT、日本与新加坡；3 轮、4 并发、8 秒超时。
本套原型用于确定未来 Flutter 桌面界面，不是 Windows 可执行程序。

界面与交互
01 主界面：网站勾选、地区选择、采样参数、高级筛选。
02 测速中：请求进度、实时结果、停止操作。
03 测速结果：ChatGPT / GitHub 独立排名与推荐，点击节点查看详情。
04 已取消：停止任务后保留上次完整报告。
05 无匹配节点：恢复默认范围。
06 连接失败：重新连接、检查设置。
07 连接设置：自动发现和手动路径输入。
08 网站管理：列表、添加、编辑、二次确认移除。
09 添加 / 编辑网站：验证名称、URL、状态码，失败保留输入。
10 节点选择：搜索、全选、清空、手动限定；空勾选使用全部匹配节点。
11 请求详情：各轮状态、首字节、总耗时和失败原因。
12 导出报告：CSV / JSON 格式，包含失败行选项。

数据与能力边界
所有节点、连接状态、报告时间、耗时和成功率均为模拟数据。
未调用 Clash、Mihomo 或公网测速接口，未读取实际配置、订阅或凭据。
默认日本 / 新加坡匹配 4 个模拟节点，两个网站、3 轮共 24 次模拟请求。
结果中有一条节点在 3 轮中通过 2 次；不进入推荐。不同网站推荐不同节点。
“刷新”“自动检测”“开始测速”仅演示交互与状态变化。
浏览文件仅展示所选文件名，不能获得未来桌面程序使用的真实绝对路径。
标题栏的最小化、最大化、关闭符号用于桌面外观展示，页面由浏览器控制。
设置和网站配置存入浏览器 localStorage；不是正式应用数据目录。
CSV / JSON 会下载本套原型的模拟报告，勿将其视为实测证据。
页面内容由 HTML/CSS/Alpine.js 实现；未把设计稿图片当作可操作界面。

视觉与动效
主操作按下 1px / 0.98 倍反馈；展开与弹窗以短促的淡入/位移说明来路。
网站结果切换使用同一块滑动选中底板；首次进入只有一次轻微出场。
支持 prefers-reduced-motion，减少动态效果时内容直接显示。
去掉设计稿的装饰英文、重复空状态说明；保留两步编号用于任务顺序。
主界面去掉名称筛选的常驻输入，放到高级筛选中，减少首屏负担。
